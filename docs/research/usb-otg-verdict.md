# iPod nano 7G USB Host / SD Case Feasibility Report
1. DWC2 Host Mode: Bootrom has no host stack (only DFU device mode and OTG test bits at 0x2000ab58). OS DWC2 driver contains host-channel register writes (0x814981c programs HCCHAR0 at 0x38400500 with DEVADDR, EPNUM, EPDIR, EPTYPE, MPS, plus HCSPLT/HCTSIZ), and implements Root Hub / Hub drivers. However, the host stack ONLY binds to the custom "iAP Interface" (CIapPortUSBHost). Mass Storage Class (MSC/BOT/SCSI) host driver is entirely absent from the OS.
2. VBUS: Input-only. PMU (I2C1 slave 0x73, reg 0x05 bits 6/3) and Tristar (slave 0x1A, reg 0x0C in TriStarVBUSProcessTask 0x8019628) only monitor external charger presence. There is no 5V boost converter hardware to power accessories from the 220mAh internal battery; the case battery must supply 5V.
3. Accessory Identification: Tristar queries accessories over Lightning ID/CC lines and maps them to legacy 30-pin Resistor IDs. ResId 20 (560 kΩ, Camera Connection Kit) signals USB host mode accessory to the connection manager.
4. Transfer Speed Estimate: DWC2 and PHY (0x3c400000) support USB 2.0 High-Speed (480 Mbps; DCFG DevSpd=0 in bootrom/OS). Real-world SD host bulk transfer would reach 15-25 MB/s (limited by DWC2 DMA/NAND writes), dropping to ~1 MB/s if throttled to Full-Speed (12 Mbps).
5. Verdict & Option Ranking:
   #1. SD via Microcontroller Bridge: Feasible. Case MCU (e.g., RP2040/ESP32-S3) acts as USB Host to the iPod in Disk Mode (NAND exposed natively as USB mass storage) to copy files at 15-20 MB/s and sign iTunesCDB with HashAB, or serves files via iAP serial at ~10-15 KB/s in OS mode.
   #2. Native OTG Host: Unfeasible. While DWC2 core has host silicon, VBUS cannot source 5V without external power, and the OS completely lacks USB Mass Storage Class drivers and filesystem mounting logic for external drives.
   #3. BT/WiFi Transfer: Impractical. BCM4330 WiFi is unrouted/disabled; Bluetooth lacks OBEX/FTP profiles (only A2DP/HID/wireless iAP) and throughput is capped at ~20-50 KB/s with no OS file listener.
