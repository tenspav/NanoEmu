# iPod nano 7G Broadcom BCM4330 / WiFi Feasibility Verdict
1. Chip Misidentification: The board DOES NOT contain a BCM4330. Physical IC teardown (iFixit) and RAM strings identify Broadcom BCM2078KUBG (ROM patch "BCM2076B1 Vincent Class 1.5 CodePatches" @ 0x0890cbfa). BCM2078 is a dedicated Bluetooth 4.0 + FM receiver combo with NO Wi-Fi silicon/die. The prior "BCM4330" note in usb-otg-verdict.md confused the Nano 7G with the contemporary iPod touch 5G.
2. RAM String Audit (dumps/snap6/ram-full.bin): 'bcm4330', '4329', '4330', 'brcmf', 'sdio' have 0 occurrences. 'wlan' is 0 (only substring in "PhotoViewLandscape"). 'mmc' is 0 (3 false-positive binary/cert chunks). 'wifi' appears 5 times: 1 generic OS subsystem tag ("WiFi\0XPC\0TouchDebug" @ 0x08016f80) and 4 A2DP coexistence adaptation methods ("BT::A2dpStreamConfig::setWifiAssociatedBitpool" @ 0x0877f525) to throttle BT bitpool when 2.4GHz noise is flagged. No Wi-Fi driver, firmware blob, or protocol stack exists.
3. MMIO Map & SDIO Host Silicon: S5L8740 has NO SDIO/MMC host controller. The MMIO space 0x38000000-0x3fffffff is fully accounted for: SHA1 (0x380), Audio DMA1/2 (0x382/0x387), LCD transport (0x383), DWC2 USB (0x384), ADSP (0x385), FMC NAND (0x38a), AES (0x38c), VIC0-2 (0x38e), Blitter (0x390), H.264 (0x396), PowerVR MBX GPU (0x3b0), and standard serial/timers (0x3c3-0x3de). Base 0x38b00000 is unmapped/unreferenced (hits in code are Thumb opcodes like 'pop {..., pc}'). The 64 OS VIC IRQ vectors contain zero SDIO/MMC handlers.
4. Physical / RF Routing & Hardware Probing: Broadcom BCM2078 connects to S5L8740 exclusively via dedicated high-speed UART 1 at 0x3db00000 (IRQ 4/5) and I2S/PCM audio for FM. Hardware ballout lacks SDIO pins (CLK, CMD, DAT0-3) and Wi-Fi RF chains. Logic board traces only route BT RF to the plastic bottom window and FM to the 3.5mm headphone ground; there is no 802.11 PA, filter, or antenna matching network. Probing lines near the BCM2078 with a logic analyzer will only show 115200 / 2.4MBaud HCI UART traffic (H4 packets, VSC 0xFC15 for FM).
5. Final Verdict: 100% UNUSABLE / IMPOSSIBLE. There is zero dormant Wi-Fi silicon in the BCM2078, zero SDIO host IP in the S5L8740 SoC, zero Wi-Fi code in firmware, and zero RF routing. Any homebrew networking must use Bluetooth PAN/RFCOMM or external MCU over Lightning/USB.
